# Project skills

Vendored copies of third-party Claude Code skills. Each directory keeps its upstream MIT license.

- `grill-with-docs`, `grilling`, `domain-modeling`: from [mattpocock/skills](https://github.com/mattpocock/skills), copyright Matt Pocock.
  `grill-with-docs` is the entry point. It runs `grilling` (interview in rounds until the design tree is resolved)
  and `domain-modeling` (maintain `CONTEXT.md` and `docs/adr/` as terms and decisions settle).
- `unslop`: from [ericlitman/open-pstack](https://github.com/ericlitman/open-pstack), originally by Lauren Tan (poteto).
  Applies to all prose written in this repo: docs, commit messages, PR bodies, chat.

To refresh a skill, re-download its `SKILL.md` from the upstream path and commit the diff.
